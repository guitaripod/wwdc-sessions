# Adopt Memory Integrity Enforcement and Pointer Authentication

**Event:** Meet with Apple · **Topic:** Privacy & Security · **Published:** 2026-03-06 · **Session:** [meet-with-apple-279](https://developer.apple.com/videos/play/meet-with-apple/279)

Learn how Memory Integrity Enforcement and Pointer Authentication work together to defend your app against memory corruption. Find out how the type-aware secure allocator leverages Memory Tagging Extensions to prevent exploitation, and how to adapt allocator wrappers and object pools to preserve hardware protections. Plus, explore how to enable Pointer Authentication in Xcode with arm64e to maintain control flow integrity. This session was originally presented as part of the Meet with Apple event “Fortify your app: Essential strategies to strengthen security.” Watch the full video for more insights and related sessions.
