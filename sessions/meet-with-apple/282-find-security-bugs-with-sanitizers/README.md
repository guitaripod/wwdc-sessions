# Find security bugs with Sanitizers

**Event:** Meet with Apple · **Topic:** Privacy & Security · **Published:** 2026-03-06 · **Session:** [meet-with-apple-282](https://developer.apple.com/videos/play/meet-with-apple/282)

Discover how Address Sanitizer and Thread Sanitizer can help you catch hidden memory corruption and concurrency issues. Learn how Address Sanitizer detects buffer overflows and use-after-free errors across Swift, C, C++, and Objective-C with byte-level precision. Explore how Thread Sanitizer uncovers elusive data races, and how to configure both tools in your automated test plans. This session was originally presented as part of the Meet with Apple event “Fortify your app: Essential strategies to strengthen security.” Watch the full video for more insights and related sessions.
