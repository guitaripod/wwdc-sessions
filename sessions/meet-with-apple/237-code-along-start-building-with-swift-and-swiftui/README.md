# Code-along: Start building with Swift and SwiftUI

**Event:** Meet with Apple · **Topic:** SwiftUI & UI Frameworks · **Platforms:** iOS, iPadOS, macOS, tvOS, visionOS, watchOS · **Published:** 2025-11-14 · **Session:** [meet-with-apple-237](https://developer.apple.com/videos/play/meet-with-apple/237)

Learn the basics of app development with Swift and SwiftUI. In this online code-along, you’ll build a simple view from an iOS demo app in Xcode, add text fields and photos to capture input, and save information using SwiftData. By the end of the session, you’ll have a complete, interactive interface. To code along, you’ll need a Mac running macOS Sonoma 14.0 or later and Xcode 15 or later. Conducted in English.
