# Code along with the Foundation Models framework

**Event:** Meet with Apple · **Topic:** AI & Machine Learning · **Platforms:** iOS, macOS · **Published:** 2025-09-15 · **Session:** [meet-with-apple-205](https://developer.apple.com/videos/play/meet-with-apple/205)

Get hands-on experience using the Foundation Models framework to access Apple’s on-device LLM. In this online session, you can code along with us as we build generative AI features into a sample app live in Xcode. We’ll guide you through implementing core features like basic text generation, as well as advanced topics like guided generation for structured data output, streaming responses for dynamic UI updates, and tool calling to retrieve data or take an action.

To actively code along, you’ll need a Mac with Apple silicon that supports Apple Intelligence running the latest release of macOS Tahoe 26 and Xcode 26.
