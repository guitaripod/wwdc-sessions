# Fine-tune your App Transport Security settings

**Event:** WWDC21 · **Platforms:** iOS, iPadOS, macOS, tvOS, watchOS · **Published:** 2021-06-16 · **Session:** [wwdc2021-10281](https://developer.apple.com/news/?id=jxky8h89)

Transport Layer Security (TLS) uses encryption to protect connections from prying eyes, and URLSession provides strong TLS connections by default with App Transport Security (https://developer.apple.com/documentation/bundleresources/information_property_list/nsapptransportsecurity) (ATS). 

If you need to connect to older servers that don't support TLS, however, you can now add ATS exceptions to your app.
