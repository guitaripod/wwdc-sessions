# HLS Authoring for AirPlay 2 Video

**Event:** WWDC19 · **Topic:** Audio & Video · **Platforms:** iOS, iPadOS, macOS, tvOS, watchOS · **Published:** 2019-06-04 · **Session:** [wwdc2019-507](https://developer.apple.com/videos/play/wwdc2019/507)
